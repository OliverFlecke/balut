# Balut on the web

A small front-end version of the [Balut](<https://en.wikipedia.org/wiki/Balut_(game)>) game!

## Development

Install dependencies with `pnpm install`.
Run the application locally on [localhost:3000](http://localhost:3000) with `pnpm dev`.

## Deployment

Deployment can be done from the CLI with `pnpm deploy`. This will build the application into static assets and deploy them to Cloudflare Workers.
